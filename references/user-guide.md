# 安装与使用

## 安装

把完整的 `hfss-codex-bingo` 文件夹放入使用者自己的 Codex skills 目录，例如 Windows 的 `%USERPROFILE%\.codex\skills\`。目录内应有 `SKILL.md`、`agents`、`references` 和 `scripts`，不要只复制入口文件。

HFSS自动控制需要 Windows、已安装并获许可的 Ansys Electronics Desktop，以及带pywin32的Python。当前原生自动化经验主要验证于HFSS 2021 R1；其他版本应先核对COM/API，不能承诺直接兼容。技能本身不包含HFSS软件或许可证。

## 能做什么

- 结合当前对话、Visio、论文、截图和现有AEDT文件，确认要复现哪个结构、哪些尺寸和区域必须保留、哪些允许修改。
- 将图形映射为介质、导体和真实开槽，建立有实际几何绑定的尺寸变量，核对层厚、连通、间隙、馈点及端口。
- 按当前设计选择单端同轴/探针S11，或差分Terminal原生Sdd/Scc；不会把一种端口套到所有天线。
- 在授权范围内配置求解、诊断收敛和内存问题，提取指定方向增益、效率、功率、方向图和频率响应。
- 分开比较论文模拟与实测、匹配低谷与辐射零点，说明做到什么、仍差什么，避免只凭外观或一个增益峰值宣布复现成功。
- 输出HFSS原生曲线、CSV、三视图、分层图及多角度3D图；需要工程交付时保留匹配结果目录并重开核验。
- 使用当前项目的交接文件续接工作，避免重复建模和重复启动正在运行的求解。

## 可以直接这样说

**Visio加论文建模：**

```text
使用 $hfss-codex-bingo，结合这份Visio和论文复现最终样机。
论文负责尺寸和材料，Visio说明我想保留的结构；先核清图号、层与开槽，再建模核对，本轮先不仿真。
```

**单独论文复现：**

```text
使用 $hfss-codex-bingo，复现论文指定图中的天线。
按论文实际馈电形式建模，未公开的接头/铜厚等细节请明确列为假设；然后仿真并分别与论文模拟和实测比较。
```

**局部修改：**

```text
使用 $hfss-codex-bingo，在现有工程的独立副本中按红框修改。
保留其余层、板、材料、端口和指定结构；先说明对应哪些物体与接口，有会改变拓扑的歧义再问我。
```

**结果和续接：**

```text
使用 $hfss-codex-bingo，先读取这个工作区的交接记录。
确认实际工程和已完成的求解，只输出我要求的频率曲线、指定方向增益和多视角图；缺少相应场数据时先说明。
```

## 需要用户提供什么

提供可访问的源文件、所选结构/样机、希望完成的工作，以及必要的修改范围。尺寸比例、材料、目标和频段如果源文件或当前对话已经明确，不必重复填写。关键缺失信息会集中询问；非关键缺项可用明确、可恢复的工程假设。

不需要使用者逐条教HFSS点击操作，也不需要为每个常规实现步骤重复确认。技能不能自行获知未提供的论文细节、看不到的旧对话，或自动保证论文全部指标达标。它理解的是本次实际提供的对话和文件；每个项目的目标、当前状态和历史结果放在该项目工作区，安装包不携带另一位用户的任务。

## 验证与交付边界

建模核对、端口可用、数值收敛和论文性能复现是不同层级。几何参数应实测并验证绑定；求解需检查整轮终态与连续收敛；频率曲线需核真实频点和场数据；交付工程需保留同名 `.aedtresults`。无授权的新拓扑、新反射结构或尺寸搜索不由技能自动启动。
