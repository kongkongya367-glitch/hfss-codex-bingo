# HFSS 2021 R1 automation notes

Names, frequencies and impedances in code examples are illustrative. Resolve them from the current model and task rather than using them as another antenna's specification.

## Connection

Use the versioned COM ProgID:

```python
import pythoncom
import win32com.client

pythoncom.CoInitialize()
try:
    app = win32com.client.GetActiveObject("Ansoft.ElectronicsDesktop.2021.1")
except Exception:
    app = win32com.client.Dispatch("Ansoft.ElectronicsDesktop.2021.1")
desktop = app.GetAppDesktop()
```

Resolve the installation dynamically; a common executable location is `AnsysEM21.1/Win64/ansysedt.exe`. Do not hardcode a drive letter in reusable automation.

With multiple Desktop instances, attach to the verified owning PID/ROT entry rather than a stale default PID or whichever instance answers the unversioned ProgID. Serialize COM operations; offline review can run separately without competing for the active project. Reused wrapper scripts may print an old trial number: identify jobs by exact project path, native command line, log, and status.

## Differential pair

Use actual terminal boundary names returned after port creation:

```python
boundary.EditDiffPairs([
    "NAME:EditDiffPairs",
    ["NAME:Pair1",
     "PosBoundary:=", positive_terminal,
     "NegBoundary:=", negative_terminal,
     "CommonName:=", "Common_1",
     "CommonRefZ:=", "25ohm",
     "DiffName:=", "Differential_1",
     "DiffRefZ:=", "100ohm",
     "IsActive:=", True],
])
```

Verify by reading the saved project and by querying the boundary/report APIs. Do not assume `P_plus:1` and `P_minus:1` are the strings required by `EditDiffPairs`; they may be source labels while the pair uses generated terminal boundary names.

## Native Sdd report

Create a `Terminal Solution Data` report with:

```python
report.CreateReport(
    "Sdd11_native_mixed_mode",
    "Terminal Solution Data",
    "Rectangular Plot",
    "Setup_2GHz : Sweep_1p5_2p5GHz",
    ["Domain:=", "Sweep"],
    ["Freq:=", ["All"]],
    ["X Component:=", "Freq",
     "Y Component:=", ["dB(St(Differential_1,Differential_1))"]],
    [],
)
```

Use `ExportToFile` for CSV. For a plot image, `ExportImageToFile` is the authoritative export. HFSS 2021 R1 can reject graphics calls made rapidly through external COM (`RPC_E_CALL_REJECTED`). Retry only after saving and making the project/design active. If rejection persists, execute the image-export script inside the graphical HFSS process with `oDesktop.RunScript`; `-ng` is not reliable for graphical report export. Never silently replace the image with an external redraw.

`scripts/native_sdd11_report.py` creates a report and saves the supplied working project. Use an authorized independent copy, actual design/solution/pair names, and a verified owning Desktop. It rejects an active project with the same stem but a different directory; do not bypass that check by overwriting the other copy.

## Radiation

Use an air/vacuum region with clearance justified by the lowest frequency, commonly about a quarter free-space wavelength unless the selected radiation boundary or reference model requires more. Assign the radiation boundary to the outer region faces/object and create an infinite sphere.

For differential far-field verification, set equal-amplitude, 180-degree-opposed terminal sources. Confirm source names from HFSS rather than inventing them. Save fields for the adaptive solution needed by far-field reports; removing those fields invalidates radiation outputs.

## Reliability rules

- Save to a new project before mutation.
- Avoid editing the user's unrelated open projects.
- Query `GetSetups`, `GetSweeps`, `GetAllReportNames`, excitations, boundaries, and nominal variation after changes.
- Treat `Normal completion` without convergence as insufficient; inspect adaptive messages.
- Do not delete solved variations or field caches merely to tidy a project. Keep any authorized cleanup separate from preserving the selected solved data and reports.
- When packaging, copy or SaveAs the project with its matching `.aedtresults`, close it, remove only its generated `.lock`, and reopen once to validate.

## Additional verified 2021 R1 pitfalls

### Rebuilt ground and terminal names

`BoundarySetup.GetExcitations()` can return alternating actual terminal names and types, for example `P_plus_T1, Lumped Port, P_minus_T1, Lumped Port`. Testing only for parent `P_plus` can miss existing excitations. Enumerate the actual assignments before rebuilding a port reference conductor. Remove/reassign only the affected boundaries in the isolated copy; query the resulting names and reject duplicates. Do not assume a generic rename succeeded when an old terminal already has that name.

Deleting a radiation boundary can also remove its sphere/reports in this version. When only resizing the air box, edit the existing creation property and verify retained assignments rather than deleting/recreating radiation postprocessing unnecessarily.

### Material/geometry command properties

A temporary Boolean tool assigned `vacuum` (zero conductivity) requires `SolveInside=True`. It is not a metallic sheet merely because it will later be subtracted. A CreatePolyline error of this type is a material-setting error, not evidence of missing administrator permission.

`GetChildObject` was unsupported on the tested 2021 Modeler COM object. The tested route for creation dimensions was:

```python
server = "Upper_Substrate:CreateBox:1"
old_xsize = str(editor.GetPropertyValue("Geometry3DCmdTab", server, "XSize"))
editor.ChangeProperty([
    "NAME:AllTabs",
    ["NAME:Geometry3DCmdTab", ["NAME:PropServers", server],
     ["NAME:ChangedProps", ["NAME:XSize", "Value:=", "(" + old_xsize + ")+ExtensionX"]]],
])
```

Use this only when that creation command actually exists and `ExtensionX` is defined. Bind permitted PCB layers and air-region clearance consistently; verify the new body bounding boxes. Do not add the same extension twice when resuming a partially prepared copy. Scalar property values need `str`, not a helper that iterates COM arrays.

### Native fields

For surface plots, query current face IDs with `GetFaceIDs` and build `PlotGeomInfo` as `[1, 'Surface', 'FacesList', count] + faces`. Tested quantities include `ComplexMag_Jsurf`, `Vector_Jsurf`, and `ComplexMag_E`. `FieldsReporter.SetPlotFolderSettings` supports `ColorMapSettings`, `Scale3DSettings`, `Marker3DSettings`, and `Arrow3DSettings`; examples in the local official guide are the authority for the versioned parameter names.

Native image export inside the GUI used `FieldsReporter.ExportPlotImageToFile(path, '', plot_name, 'Global')`. A tested grid-export sequence was:

```python
fields.CalcStack("clear")
fields.EnterQty("E")
fields.ExportOnGrid(
    path, minimum_xyz_with_units, maximum_xyz_with_units, spacing_xyz_with_units,
    "Setup_2GHz : LastAdaptive", ["Freq:=", "2GHz", "Phase:=", "0deg"],
    False, "Cartesian", ["0mm", "0mm", "0mm"],
)
fields.CalcStack("clear")
```

Verify header/column layout and ordering for each grid definition. `RadField.GetSetupNames` required the argument `'Infinite Sphere'` in the tested version. Do not guess sphere names; the case name `Sphere_2GHz` is not universal.

### Recover errors with evidence

Read native Desktop messages after a COM exception and correct the identified cause before retrying. Keep shell parsing/quoting failures separate from HFSS errors. Prefer a file-based Python script over deeply nested PowerShell/regex quoting for substantial automation.

A local API example for mesh linking is documentation, not proof the mesh-link workflow has been executed or validated. Verify the exact version, geometry compatibility, source-solving side effects, and solver provenance before adopting it. Do not automatically solve or modify a preserved partner project.

## Port, view, and numerical details

- For a circular via, use planar cap face centers and cap area to establish the cylinder center; seam vertices can be displaced by the radius. Recheck actual contacts and ground-hole isolation.
- Zero-order versus Mixed basis and direct versus iterative execution are distinct. In one 2021 R1 case, zero-order forced direct execution and required tetrahedral edges below wavelength/20. Check the installed documentation and actual runtime profile before treating a configuration as an eligible iterative control. A saved `UseIterativeSolver=True` alone proves neither execution nor accuracy.
- Official `desktopproxy -cleanstop <exact-project>` requests orderly stopping; checkpoint first. If native abort becomes necessary, use its official interface after a recoverable copy. Preserve the log and actual exit status; a disappeared process without a terminal record is an unknown interruption, not proof of OOM or convergence.
- `GetChildObject`/property-tree calls can be unimplemented on a particular installation even when listed in the manual. Inspect the native error and use supported property APIs or the verified GUI; do not blindly repeat failing calls.
- Native 3D report cameras are not the geometry modeler's camera. `SetActiveDesign`/`SetActiveProject` can change the active editor. Activate the intended 3D report before GUI orientation commands and recheck the window title. See `frequency-reports-and-views.md` for camera-only exports.
