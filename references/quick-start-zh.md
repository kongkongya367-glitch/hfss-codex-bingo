# HFSS Codex Bingo 快速使用

把完整技能文件夹放进自己的 Codex skills 目录。准备好带许可证的 HFSS 与可用 Python/pywin32；当前自动化主要验证于 HFSS 2021 R1。

提供 Visio、论文、截图或现有工程，然后说：

```text
使用 $hfss-codex-bingo，理解这段对话和附件里的建模要求，复现我指定的结构。
先确认尺寸来源、层、槽和馈电方式；按我当次要求完成建模、核对、仿真或报告。
论文没有公开的细节请列为假设，不要把其他项目的目标套过来。
```

技能可以帮助理解局部修改、生成参数化HFSS模型、处理单端或差分端口、核收敛、生成原生S参数/指定方向增益/效率曲线，以及三视图、分层图和多视角辐射图。

续接项目时，让它先读项目目录的 `HFSS_RESUME.md`、`HFSS_TASK_STATE.json` 和 `HFSS_TARGET_PLAN.md`（若存在），再核实际工程和进程。技能不需要你的旧工程编号或固定频率才能工作，也不会随安装包导入另一位用户的目标、结果或对话记忆。

仅要求核对、解释或导出现有结果时，不自动改尺寸或求解；缺少你明确要求的新数据时，会说明需要补算什么。工程交付保留 `.aedt` 和匹配 `.aedtresults`，性能结论按实际证据标注。

更多示例见 [user-guide.md](user-guide.md)。
